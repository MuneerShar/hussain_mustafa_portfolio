# Hussain Mustafa — Professional Portfolio

A responsive, multi-page static portfolio website built from the information in the supplied `Hussain_Mustafa_CV_Reviewed.docx`.

## Pages
- `index.html` — Home
- `about.html` — Profile
- `education.html` — Education and workshops
- `experience.html` — Internship experience
- `research.html` — Undergraduate thesis and objectives
- `certifications.html` — Online certifications
- `skills.html` — Technical and language skills
- `community.html` — Memberships and volunteering
- `contact.html` — Contact and academic references

## Structure
- `assets/css/styles.css` — All site styling and responsive layouts
- `assets/js/main.js` — Shared navigation, mobile menu, reveal effects, footer year
- `assets/documents/Hussain-Mustafa-CV.docx` — Downloadable CV
- `assets/images/` — Place for optional profile/project images

## Preview locally
Open `index.html` in a browser. For best results, use VS Code Live Server or another local static server.

## Deploy to Netlify
1. Extract the ZIP.
2. In Netlify, choose **Add new site → Deploy manually** (or drag-and-drop deploy).
3. Upload the extracted website folder (the folder containing `index.html`).
4. Netlify will publish it. You can connect a custom domain from **Domain management**.

## Notes
- All supplied CV information is retained in the website; no additional qualifications or experience have been invented.
- The hero artwork is an original inline vector illustration, so the site does not depend on an unavailable profile photo.
- Google Fonts are loaded online; the layout has fallback fonts if they cannot load.
- Check phone, email, LinkedIn and certificate links before public launch.
